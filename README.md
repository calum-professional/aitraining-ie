# aitraining.ie

A simple static website listing AI courses from Professional Training, built with plain HTML, CSS and JavaScript.

> Full documentation (running locally, replicating for a new site, deployment, troubleshooting) will be written in Phase 6.

**Quick start:** open the folder in VS Code, right-click `index.html` → **Open with Live Server**.
All site-specific settings are in `js/config.js`.
